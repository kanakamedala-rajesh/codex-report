# Patch archive

This directory keeps conversation-generated patch files supplied during the
project's development. The initial implementation was built with GPT-6-PRO in a
ChatGPT conversation; later patch artifacts are preserved here as part of that
development record.

Patch files are historical diffs and may target a specific earlier tree. Review
their base and contents before applying them. The current source tree and Git
history are authoritative. Patch archives do not replace release notes or
contributor attribution.
