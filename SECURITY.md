# Security policy

## Supported versions

No stable npm release is available yet. Development builds, including
`0.0.1-dev`, are not covered by a security support guarantee. After the first
stable release, this project will document the supported release line here.

## Reporting a vulnerability

Please report security issues through [GitHub Private Vulnerability Reporting](https://github.com/kanakamedala-rajesh/codex-report/security/advisories/new).
Do not report a vulnerability in a public issue or pull request, and do not
attach real Codex session data, credentials, or private configuration.

The repository owner must enable GitHub's private vulnerability reporting
feature before the repository is made public. If the private report form is not
available, do not publish exploit details; first use the repository's GitHub
profile contact options to request a private reporting channel.
