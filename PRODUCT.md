# Codex Report

A local desktop analytics workspace for developers using Codex CLI. Read token
usage per session/turn, distinguish interruptions and usage-limit failures,
compare observed API-equivalent estimates, inspect quota snapshots and collection
health, and edit dashboard/billing preferences. All metrics must come from the
existing reporting API. Unknown prices remain unknown; no inferred entitlement.
No prompts, telemetry, external media or provider requests are introduced.

The user prioritizes comfortable reading on computers over compactness or mobile
layouts. Browser zoom, keyboard access and narrower desktop windows remain useful.
Existing data, settings revisions and token accounting must not change.
